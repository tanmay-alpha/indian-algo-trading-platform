# Production Readiness Checklist

> Complete this checklist before declaring a system production-ready.
> Generated by ai-workspace.

---

## Code Quality

- [ ] All tests pass in CI
- [ ] Code coverage is acceptable (aim for >70% on critical paths)
- [ ] No known critical bugs outstanding
- [ ] No TODO/FIXME comments in critical code paths
- [ ] Code has been reviewed by at least one other person or AI agent

---

## Security

- [ ] Security checklist completed (see SECURITY_CHECKLIST.md)
- [ ] Secret scan passed (no credentials in history)
- [ ] All dependencies up to date and audited
- [ ] Authentication and authorization tested

---

## CI/CD

- [ ] CI pipeline passes on `main` branch
- [ ] Deployment pipeline is automated
- [ ] Rollback procedure is documented and tested
- [ ] Environment-specific configs are managed via env vars (not hardcoded)

---

## Observability

- [ ] Structured logging is in place
- [ ] Errors are captured and alerted (e.g., Sentry, Datadog)
- [ ] Key metrics are tracked (latency, error rate, throughput)
- [ ] Health check endpoint exists (`/health` or equivalent)
- [ ] Runbook documents how to respond to common failures

---

## Data

- [ ] Database migrations are reversible
- [ ] Backups are configured and tested
- [ ] Sensitive data is encrypted at rest
- [ ] PII handling is documented and compliant

---

## Performance

- [ ] Response time meets SLA targets (p95)
- [ ] Load testing completed for expected traffic
- [ ] Database queries are indexed appropriately
- [ ] No N+1 query issues on critical paths

---

## Documentation

- [ ] README is up to date
- [ ] API documentation exists (OpenAPI / Swagger or equivalent)
- [ ] Architecture decision records (ADRs) are up to date
- [ ] Deployment process is documented in README or runbook

---

## Operations

- [ ] On-call / support process is defined
- [ ] Incident response plan exists
- [ ] Secrets rotation process is documented
- [ ] Rate limits and timeouts are configured
