# Release Checklist

> Complete before tagging and deploying a release.
> Generated by ai-workspace.

---

## Pre-Release

- [ ] All features for this release are merged to `main`
- [ ] All CI checks pass on `main`
- [ ] CHANGELOG or release notes are written
- [ ] Version number is updated (pyproject.toml / package.json / version file)
- [ ] Production readiness checklist reviewed

## Testing

- [ ] Full test suite passes
- [ ] Smoke test on staging environment passes
- [ ] Critical user flows manually verified on staging
- [ ] Database migration (if any) tested on staging data

## Security

- [ ] Secret scan passes
- [ ] No new high/critical CVEs in dependencies
- [ ] API keys and credentials are rotated if needed

## Deployment

- [ ] Deployment runbook is current
- [ ] Database backup taken before migration
- [ ] Rollback plan confirmed
- [ ] Deployment scheduled during low-traffic window (if applicable)
- [ ] Team / stakeholders notified of deployment

## Post-Release

- [ ] Health check confirms service is running
- [ ] Key metrics look normal (error rate, latency)
- [ ] Release tag created in git (`git tag v0.x.y`)
- [ ] Release notes published (GitHub Releases / changelog)
- [ ] Monitoring alert thresholds reviewed
